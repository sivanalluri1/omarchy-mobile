# Development steps

Run commands from the repository root. Local scripts build and inspect only; none flashes or reboots the tablet.

## 1. Builder

`docker build -t omarchy-p613-builder:llvm19 -f buildenv/Dockerfile .`

Validate Linux/aarch64, clang/LLD and make, recording package versions. The Docker base digest is pinned; Debian package versions are captured for each built image but the apt repository is not snapshot-pinned yet.

## 2. Vendor configuration

`bash scripts/kernel-build.sh configure`

Uses sources.lock.json's kernel revision and vendor/atoll-perf_defconfig plus vendor/gta4xlve.config. Saves the resolved .config and differences from the live tablet baseline. Review differences before compiling.

## 3. Unchanged-source compile

`bash scripts/kernel-build.sh build`

Uses four jobs by default. Logs and outputs live in build/kernel-baseline. Review the final exit status, Image, DTBs/DTBO, provenance and source cleanliness. No boot image is generated by this command.

## 4 onward

Follow PLAN.md in sequence. Recovery preparation and hardware testing require evidence unavailable from a source build. Record the next dependency in PROGRESS.md; never advance its checkbox on the strength of a compile alone.
